# Day 08 - Database and Laravel API

## Objective
To understand relational databases and create backend APIs using Laravel.

## Database
The project uses a hygiene management database with three tables:

- Facilities
- Inspections
- Complaints

## SQL Concepts
- SELECT queries
- JOIN operations
- GROUP BY
- WHERE conditions
- Foreign key relationships

## API Operations
The Facilities API includes:

- GET: Retrieve facilities
- POST: Create a facility
- PUT: Update a facility
- DELETE: Delete a facility

## Project Files
- sql/queries.sql
- database/schema.sql
- laravel-api/routes/api.php
- laravel-api/app/Http/Controllers/FacilityController.php

## Note
The Laravel source files are prepared for the API structure.
A complete Laravel installation and database configuration are required to run the API.
